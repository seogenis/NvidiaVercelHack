# 🏆 We just won 2nd at the NVIDIA Hackathon 🏆 
**...with a Jensen Huang-signed GPU!**

**Santa Clara University SCU AI Collaborate** members competed at the **NVIDIA AI x Vercel Hackathon** in San Francisco against hundreds of programmers from around the world.

## Our Project
We built an **AI agent** that:
- **Operates your computer** using speech prompts
- **Generates entire websites** with interactive learning materials
- **Reduces teacher prep time** for lectures
- **Makes learning more engaging** for students

### Tech Stack
- **Nvidia Nemotron 70b model**
- **Nvidia Parakeet model**
- **Vercel's v0 tool**
- **PyAutoGUI** (for controlling your computer programmatically)
